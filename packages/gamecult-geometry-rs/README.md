# GameCult.Geometry for Rust

Rust projection of the GameCult.Geometry v2 document contract. It owns the
typed MessagePack layouts and stable geometry record identities used at the
Rust boundary; it does not depend on VibeGeometry or `vg-csg`.

The initial contract and stable-hash implementation were mined from the
MIT-licensed GameCult `vg-csg` crate at commit `8f070f4`. The implementation
was rewritten here under GameCult.Geometry ownership. The original copyright
and MIT terms are preserved in [LICENSE](LICENSE).
